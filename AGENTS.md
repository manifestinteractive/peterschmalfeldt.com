# Project Guidance

## Stack

- This repository builds a static website with Gulp, Panini, Sass, and vanilla JavaScript.
- Use Node `14.19.0` from `.nvmrc` unless the user explicitly requests a toolchain change.
- Prefer the existing npm scripts instead of ad hoc build commands.

## Commands

- `npm install`
- `npm start` starts BrowserSync at `http://localhost:8081`
- `npm run build:dev`
- `npm run build:staging`
- `npm run build:production`
- `npm test`
- `npm run lint:js`
- `npm run lint:html`

## Source Layout

- `src/html/pages/` contains page entrypoints.
- `src/html/layouts/`, `src/html/includes/`, `src/html/helpers/`, and `src/html/data/` support the Panini HTML build.
- `src/scss/` contains Sass source files.
- `src/js/` contains site JavaScript source files.
- `src/images/` contains source images.

## Generated Output

- `build/` and `dist/` are generated output.
- `src/assets/css/style.css` is generated by the Sass pipeline and should not be hand-edited unless the user explicitly asks for that.

## Editing Rules

- Prefer editing source files under `src/`.
- Keep changes backward compatible unless the user explicitly approves broader refactors.
- Preserve the existing ESLint Standard style and the current HTML/layout structure.
- Do not upgrade Node, npm, Gulp, Sass, or major build dependencies unless the user explicitly requests that work.

## Skills

- Repo-local Codex skills live under `.agents/skills/`.
- For copywriting, SEO metadata, headings, CTAs, summaries, or positioning updates for peterschmalfeldt.com, use the `peter-site-copy` skill first.
- Do not use `peter-site-copy` for code-only changes that do not affect site messaging.
